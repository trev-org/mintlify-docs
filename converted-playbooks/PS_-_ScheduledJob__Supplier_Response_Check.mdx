## Workflow

<Steps>
  <Step title="Initiate Incident Fields" icon="terminal">
    commands.local.cmd.set.incident

    **Executes Command:** `!setIncident`
    **Full Path:** `Builtin|||setIncident`

    <Accordion title="Command Arguments (1)" icon="terminal">

    | Argument | Value |
    |----------|-------|
    | `suppliernoresponsereceived` | `` |

    </Accordion>

  </Step>
  <Step title="Get Supplier Email" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    Set a value in context under the key you entered.

    **Executes Script:** `Set`

    <Accordion title="Script Arguments (2)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `key` | `Supplier List` |
    | `value` | `${lists.CSIRT Suppliers Email Communication}` → `split(delimiter={'value': {'simple': ','}})` → `StringToArray()` |

    </Accordion>

  </Step>
  <Step title="Get Today's Date" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    Retrieves the current date and time.

    **Executes Script:** `GetTime`

  </Step>
  <Step title="Format Today's Date" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    **Executes Script:** `ConvertXSOARDatetoEWSDate`

    <Accordion title="Script Arguments (1)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `TodaysDate` | `${TimeNow}` |

    </Accordion>

  </Step>
  <Step title="PS - Subplaybook: ScheduledJob Supplier Response Check" icon="diagram-project">
    <Tip>
    **Calls Sub-Playbook:** `PS - Subplaybook: ScheduledJob Supplier Response Check`
    
    This sub-playbook shares the current context and can access all available data.
    </Tip>

    <Accordion title="Loop Configuration" icon="rotate">

    | Setting | Value |
    |---------|-------|
    | Wait Between Iterations | 1 second(s) |
    | Maximum Iterations | 100 |

    </Accordion>

    <Accordion title="Sub-Playbook Inputs" icon="right-to-bracket">

    | Input Parameter | Value |
    |-----------------|-------|
    | `List Entry` | `${Supplier List}` → `replace(limit={})` → `replace(limit={})` +4 |
    | `Today's Date` | `Formatted Todays Date` → `SetIfEmpty(applyIfEmpty={})` |

    </Accordion>

  </Step>
  <Step title="Are there suppliers we didn't receive a reply from?" icon="code-branch">
    <Tabs>
      <Tab title="Otherwise">
        **Proceeds to:** Set Supplier Incident Field to "N/A"
      </Tab>
      <Tab title="Yes">
        **Proceeds to:** Send Email Receipt 
      </Tab>
    </Tabs>

    <Accordion title="Condition Logic Details" icon="code">

    **Branch: yes**

    - `incident.suppliernoresponsereceived` **is not empty**

    </Accordion>

  </Step>
  <Step title="Send Email Receipt" icon="terminal">
    Sends an email.

    **Executes Command:** `!send-mail`
    **Integration:** EWSO365_testing
    **Full Path:** `EWSO365_testing|||send-mail`

    <Accordion title="Command Arguments (3)" icon="terminal">

    | Argument | Value |
    |----------|-------|
    | `body` | `The scheduled job that checks if an email reply has been received from vendors for CSIRT has completed.   An email reminder for a reply has been sent to: ${incident.suppliernoresponsereceived}.   Please see #${incident.id} for more details.` |
    | `subject` | `[#${incident.id}] Supplier Response Scheduled Job Check` |
    | `to` | `leticia.gomes@mdlz.com` |

    </Accordion>

  </Step>
  <Step title="Set Supplier Incident Field to &quot;N/A&quot;" icon="terminal">

    **Full Path:** `Builtin|||setIncident`

    |----------|-------|
    | `suppliernoresponsereceived` | `N/A` |

    </Accordion>

  </Step>
