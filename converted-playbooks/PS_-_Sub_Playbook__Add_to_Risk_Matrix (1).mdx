## Workflow

<Steps>
  <Step title="Risk &#40;event&#41; Source Detection conditional?" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    **Executes Script:** `RBA_Detection_Check`

    <Accordion title="Script Arguments (1)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `detection` | `incident.detectionname` → `SetIfEmpty(applyIfEmpty={})` |

    </Accordion>

  </Step>
  <Step title="Entity Field Populated?" icon="code-branch">
    <Tabs>
      <Tab title="Hostname">
        **Proceeds to:** Check if Host is Server
      </Tab>
      <Tab title="Ip">
        **Proceeds to:** Is IP internal?
      </Tab>
      <Tab title="Nothing Passed">
        **Proceeds to:** Print Message
      </Tab>
      <Tab title="User">
        **Proceeds to:** Is it an A-, S-, G- account? 
      </Tab>
    </Tabs>

    <Accordion title="Condition Logic Details" icon="code">

    **Branch: User**

    - `inputs.entityType` **equals** `user`

    **AND**

    - `inputs.entity` **is not empty**

    **Branch: Hostname**

    - `inputs.entityType` **equals** `host`

    **AND**

    - `inputs.entity` **is not empty**

    **Branch: IP**

    - `inputs.entityType` **equals** `ip`

    **AND**

    - `inputs.entity` **is not empty**

    **Branch: Nothing Passed**

    - `inputs.entity` **is empty**

    </Accordion>

  </Step>
  <Step title="Check if Host is Server" icon="code-branch">
    **Evaluates:**
    - `detectionname`: `incident.detectionname` → `SetIfEmpty(applyIfEmpty={})`
    - `hostname`: `${inputs.entity}`

    <Tabs>
      <Tab title="Otherwise">
        **Proceeds to:** Print message
      </Tab>
      <Tab title="Domaincontrollerauth">
        **Proceeds to:** Print Message
      </Tab>
      <Tab title="False">
        **Proceeds to:** VIP Host?
      </Tab>

        **Proceeds to:** Set Impact Context Key (1.5)
      </Tab>
    </Tabs>

  </Step>
  <Step title="Print message" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    Prints text to war room (Markdown supported)

    **Executes Script:** `Print`

    <Accordion title="Script Arguments (1)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `value` | `Unknown if host is server` |

    </Accordion>

  </Step>
  <Step title="VIP Host?" icon="code-branch">

      </Tab>

        **Proceeds to:** Set Impact Context Key (1.25)
      </Tab>

    **Branch: yes**

    </Accordion>

    |----------|-------|

    </Accordion>

  </Step>
  <Step title="Add to Risk Matrix" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    **Executes Script:** `RBA-Add-to-Risk-Matrix`

    <Accordion title="Script Arguments (10)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `entity` | `inputs.entity` → `splitAndTrim(delimiter={'value': {'simple': ','}})` |
    | `entityType` | `${inputs.entityType}` |
    | `impact` | `${impact}` |
    | `incidentID` | `${incident.id}` |
    | `origRiskLevel` | `incident.labels.alert\.severity` → `SetIfEmpty(applyIfEmpty={})` → `dbea7c93-733f-4c87-8a40-6d430c5afca3()` |
    | `relevance` | `${RelevanceScore}` |
    | `riskSource` | `incident.detectionname` → `SetIfEmpty(applyIfEmpty={})` |
    | `riskTime` | `${incident.occurred}` |
    | `status` | `${incident.status}` |
    | `tp_rate` | `${TPRateScore}` |

    </Accordion>

  </Step>
  <Step title="Delete Context" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    Delete field from context.
    This automation runs using the default Limited User role, unless you explicitly change the permissions.
    For more information, see the section about permissions here:
    - For Cortex XSOAR 6 see https://docs-cortex.paloaltonetworks.com/r/Cortex-XSOAR/6.x/Cortex-XSOAR-Playbook-Design-Guide/Automations
    - For Cortex XSOAR 8 Cloud see https://docs-cortex.paloaltonetworks.com/r/Cortex-XSOAR/8/Cortex-XSOAR-Cloud-Documentation/Create-a-script
    - For Cortex XSOAR 8.7 On-prem see https://docs-cortex.paloaltonetworks.com/r/Cortex-XSOAR/8.7/Cortex-XSOAR-On-prem-Documentation/Create-a-script

    **Executes Script:** `DeleteContext`

    <Accordion title="Script Arguments (3)" icon="code">

    | Argument | Value |
    |----------|-------|

    </Accordion>

  </Step>
