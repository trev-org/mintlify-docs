## Workflow

<Steps>
  <Step title="Extract Supplier Email" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    Set a value in context under the key you entered.

    **Executes Script:** `Set`

    <Accordion title="Script Arguments (2)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `key` | `Supplier Email` |
    | `value` | `inputs.List Entry` → `RegexExtractAll(error_if_no_match={})` → `trim()` |

    </Accordion>

  </Step>
  <Step title="Extract Sent Date" icon="user">
    <Warning>
    **Manual Task:** This step requires human intervention and decision-making.
    </Warning>

    Set a value in context under the key you entered.

    **Executes Script:** `Set`

    <Accordion title="Script Arguments (2)" icon="code">

    | Argument | Value |
    |----------|-------|
    | `key` | `Sent Date` |
    | `value` | `inputs.List Entry` → `RegexExtractAll(error_if_no_match={})` → `trim()` |

    </Accordion>

  </Step>
  <Step title="Search Mailbox" icon="terminal">
    Searches for items in the specified mailbox. Specific permissions are needed for this operation to search in a target mailbox other than the default.

    **Executes Command:** `!ews-search-mailbox`
    **Integration:** EWSO365_testing
    **Full Path:** `EWSO365_testing|||ews-search-mailbox`

    <Accordion title="Command Arguments (2)" icon="terminal">

    | Argument | Value |
    |----------|-------|
    | `limit` | `3` |
    | `query` | `from:"${Supplier Email}" received:${Sent Date}..${inputs.Today\'s Date}` |

    </Accordion>

  </Step>
  <Step title="Do we have a reply?" icon="code-branch">
    <Tabs>
      <Tab title="Otherwise">
        **Proceeds to:** Send Supplier Email
      </Tab>
      <Tab title="Yes">
        **Proceeds to:** Remove Supplier Email, Key-Value Pair to List
      </Tab>
    </Tabs>

    <Accordion title="Condition Logic Details" icon="code">

    **Branch: yes**

    - `EWS.Items` **is not empty**

    </Accordion>

  </Step>
  <Step title="Remove Supplier Email, Key-Value Pair to List" icon="terminal">
    commands.local.cmd.list.remove

    **Executes Command:** `!removeFromList`
    **Full Path:** `Builtin|||removeFromList`

    <Accordion title="Command Arguments (2)" icon="terminal">

    | Argument | Value |
    |----------|-------|
    | `listData` | `{${Supplier Email}: ${Sent Date}}` |
    | `listName` | `CSIRT Suppliers Email Communication` |

    </Accordion>

  </Step>
  <Step title="Send Supplier Email" icon="terminal">
    Sends an email.

    **Executes Command:** `!send-mail`
    **Integration:** EWSO365_testing
    **Full Path:** `EWSO365_testing|||send-mail`

    <Accordion title="Command Arguments (3)" icon="terminal">

    | Argument | Value |
    |----------|-------|
    | `body` | `Hi,    CSIRT would like to follow up on MDLZ CSIRT's previous communication. We have not yet received a response on the requested information.   Responses to our questions will help us understand if there is any concern or impact to MDLZ data and systems as a result of the incident experienced.    We eagerly await your responses to these questions. If it is better to have a call and discuss please let us know, we would be happy to facilitate a conversation.   Thank you,   MDLZ CSIRT` |
    | `subject` | `Test Email for No Reply` |
    | `to` | `${Supplier Email}` |

    </Accordion>

  </Step>
  <Step title="Append to Supplier Email Not Received Field" icon="terminal">
    commands.local.cmd.set.incident

    **Executes Command:** `!setIncident`
    **Full Path:** `Builtin|||setIncident`

    <Accordion title="Command Arguments (1)" icon="terminal">

    | Argument | Value |
    |----------|-------|
    | `suppliernoresponsereceived` | `incident.suppliernoresponsereceived` → `append(item={'value': {'simple': '${Supplier Email}'}, 'iscontext': True})` → `join(separator={'value': {'simple': ','}})` +2 |

    </Accordion>

  </Step>
</Steps>
